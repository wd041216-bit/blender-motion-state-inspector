# Roadmap

## V0.2: Stronger Motion Understanding

- Frame-to-frame velocity and acceleration.
- Dense event ranges for jumps, landings, spins, punches, falls, and rolls.
- Contact windows for feet, hands, head, props, and other actors.
- Left/right limb crossover detection.
- Motion-facing vs body-facing consistency checks.
- Compact spatial packets for text-only agents.
- Actor-centric top-K relation pruning for prop-rich scenes.
- Temporal range merging for repeated pose/spatial facts.

## V0.3: Visual Evidence

- Keyframe selection.
- Front/side/top screenshots.
- Skeleton and bbox overlays.
- Trajectory overlays.
- Anomaly heatmaps.

## V0.4: Agent Protocols

- MCP server mode.
- Authenticated local socket.
- Stable JSON schema versioning.
- Streaming frame diagnostics.

## V0.5: Broader Asset Support

- More rig naming conventions.
- Shape key values.
- Material and texture diagnostics.
- Non-Blender DCC export adapters.
